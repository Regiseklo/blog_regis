# Veille du 27/11/2026

Thème : la cybersécurité et l'évolution du métier d'administrateur réseau dans les infrastructures actuelles.

## Microsoft supprime le rôle de serveur WSUS dans Windows Server 2028
*Source : BleepingComputer · publié le 27/11/2026* · [Lire l'article](https://www.bleepingcomputer.com/news/microsoft/microsoft-removes-wsus-server-role-in-windows-server-2028/)

Microsoft a annoncé la suppression prochaine du rôle de serveur WSUS dans la future version majeure de son système d'exploitation, Windows Server 2028. Cette décision marque un tournant dans la gestion traditionnelle des mises à jour au sein des infrastructures d'entreprise.

**Pour un administrateur réseau :** L'administrateur réseau devra impérativement adapter ses méthodes et se tourner vers des solutions alternatives pour assurer la gestion et le déploiement des correctifs.

## Drupal met en garde contre une nouvelle faille de prise de contrôle de site exploitée lors d'attaques
*Source : BleepingComputer · publié le 27/11/2026* · [Lire l'article](https://www.bleepingcomputer.com/news/security/drupal-warns-of-new-access-bypass-flaw-exploited-in-attacks/)

L'équipe de sécurité de Drupal a signalé qu'une deuxième vulnérabilité critique est actuellement exploitée par des attaquants. Cette faille permet de compromettre et de pirater des sites web qui n'ont pas encore été mis à jour.

**Pour un administrateur réseau :** Il devient crucial pour l'équipe technique de surveiller étroitement les correctifs et d'appliquer les mises à jour de sécurité sans délai pour protéger les applications web hébergées.

## SAP confirme un incident de sécurité après une activité suspecte sur GitHub
*Source : BleepingComputer · publié le 27/11/2026* · [Lire l'article](https://www.bleepingcomputer.com/news/security/sap-confirms-security-incident-after-suspicious-github-activity/)

L'entreprise SAP a confirmé à BleepingComputer qu'elle a pris des mesures d'urgence pour protéger ses clients après avoir détecté des agissements suspects dans son environnement informatique. L'alerte a été déclenchée suite à une activité anormale repérée sur la plateforme GitHub.

**Pour un administrateur réseau :** Cette situation rappelle aux administrateurs la nécessité de renforcer la surveillance des environnements de développement et des dépôts de code tiers connectés au réseau.

## Microsoft pousse un correctif d'urgence pour résoudre les plantages de Windows Server
*Source : BleepingComputer · publié le 27/11/2026* · [Lire l'article](https://www.bleepingcomputer.com/news/microsoft/new-out-of-band-oob-emergency-hotpatch-fixes-windows-server-2025-crashes/)

Microsoft a publié une mise à jour corrective d'urgence afin de régler les plantages de Windows Server 2025. Ces incidents techniques avaient été provoqués par l'installation du correctif de sécurité mensuel précédent.

**Pour un administrateur réseau :** L'exploitant réseau doit désormais intégrer une phase de test plus rigoureuse avant de déployer les patchs pour éviter des interruptions de service imprévues.

## Une nouvelle faille Linux NFS2ROOT permet à des attaquants d'obtenir les privilèges root
*Source : BleepingComputer · publié le 27/11/2026* · [Lire l'article](https://www.bleepingcomputer.com/news/security/new-nfs2root-linux-flaw-can-let-attackers-gain-root-privileges/)

Une vulnérabilité critique vieille de 12 ans dans le serveur NFS du noyau Linux, référencée CVE-2026-99362, a été mise en lumière. Elle offre la possibilité à des attaquants distants d'obtenir les privilèges root sur les systèmes ciblés.

**Pour un administrateur réseau :** Ce type de découverte oblige les gestionnaires d'infrastructure à auditer leurs services de fichiers et à appliquer rapidement les correctifs du noyau pour contrer l'élévation de privilèges.
